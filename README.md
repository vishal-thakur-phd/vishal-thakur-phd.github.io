# Vishal Thakur — Academic website

A responsive academic website with research, publications, CV, and profile sections.

## Update the website

Edit `index.html` to update the profile. Add a CV PDF under `assets/` and replace the CV status with a link when available. Add the verified Google Scholar profile URL and publication details when supplied.

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, **main**, and **/ (root)**. The expected site address is https://vishal-thakur-phd.github.io/.

Research data and private progress notes belong in the separate private research repository.
